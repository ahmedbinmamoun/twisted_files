Twisted Files is an interactive crime investigation game that puts the player in the role of a detective responsible for solving mysterious cases through evidence analysis and suspect interrogation.
Players explore crime scenes, examine clues, and question multiple suspects while identifying contradictions and hidden motives. Each case is designed to challenge critical thinking and decision-making, where every choice can influence the investigation outcome.


Modern file explorer built with Flutter using Clean Architecture.
Fast, minimal, and designed for smooth file management experience.


## 🚀 Features
- 📂 Smart file browsing & organization
- ⚡ Fast local file access
- 🎨 Clean modern UI
- 🧩 Modular architecture (Scalable & maintainable)


## 🛠️ Tech Stack
- Flutter (Dart)
- Clean Architecture
- Dependency Injection
- Modular Feature-based Structure
- Custom Navigation System


## 📂 Project Structure
```plaintext
lib/
├── config/
│   └── di/                 # Dependency Injection setup
│
├── core/
│   ├── constants/          # App constants
│   ├── navigation/         # Routing & navigation logic
│   ├── theme/              # App themes (Light/Dark)
│   └── utils/              # Helpers & utilities
│
├── data/
│   ├── data_source/        # Local data sources
│   ├── mapper/             # Model mappers
│   ├── models/             # Data models
│   └── repositories/       # Repository implementations
│
├── domain/
│   ├── entities/           # Business entities
│   ├── repositories/       # Abstract repositories
│   └── use_cases/          # Application use cases
│
├── features/               # UI features (modular)
│
└── main.dart               # App entry point
```
